# FJSP 学习笔记

## 项目背景

FJSP（柔性作业车间调度问题）是生产调度领域的经典NP-hard问题，近年来深度强化学习、图神经网络等方法在该领域展现出强大的求解潜力。

本项目记录个人在学习FJSP问题过程中的思考、理解和总结，内容涵盖问题建模、求解方法、环境设计等多个方面。主要通过复现相关论文实验，深入理解FJSP问题的本质和求解方法。

**说明**：文中内容为个人学习过程中的思考和理解，可能存在不准确或不完善之处，欢迎大家提出疑问、指出问题，期待与领域内的同学们一起交流学习。
